## ⚡ Quick Start (5 Minutes)

```
1. Create Kaggle account → kaggle.com
2. Join competition → Click "Join Competition"
3. Create notebook → Click "Code" → "New Notebook"
4. Enable GPU → Settings → Accelerator → GPU
5. Copy code → Paste kaggle-beginner-notebook.py
6. Run → Click "Run All"
7. Wait 30-90 min → Your model trains!
8. Submit → Download submission.csv and submit
9. 🎉 You're on the leaderboard!
```
